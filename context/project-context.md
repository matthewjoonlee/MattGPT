# Project context

**What this is:** MattGPT — Fitbit/Google Health + calendar + self-logged outcomes, analyzed with real statistical/causal rigor.

**Who it's for:** Matthew — a Notre Dame student. The builder and the subject being studied are the same person; this only works because of that.

**Why it exists:** every commercial wearable coach (Google Health/Gemini Coach, Whoop Coach, Oura Advisor) needs daily engagement to justify a subscription, which structurally biases them toward always having something encouraging to say. This project has no such incentive — it can say "no signal here" honestly, validate its claims against real outcomes only Matthew knows (grades, interview results), and let the methodology be fully inspected rather than trusting a black-box score.

**Full detail:** see `../MattGPT-Outline.md` for the complete brainstorm, architecture, use-case pillars, and roadmap.
